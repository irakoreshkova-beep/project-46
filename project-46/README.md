# PROJECT 46

Персональный fitness & recovery planner для Ирины.

## Запуск

```bash
cd project-46
python3 -m http.server 4174
```

Открыть `http://localhost:4174`.

## Что входит в MVP

- автоматический план дня по дню недели;
- недельный план с тремя силовыми тренировками;
- тренировки A, B и C с домашними заменами;
- карточки техники и оценка сложности последнего подхода;
- короткий вечерний чек-ин;
- утренний ввод веса, график и среднее за 7 дней;
- локальное сохранение данных и PWA-режим.
- безопасная синхронизация между устройствами через Supabase Auth.

Настройка облака описана в [SUPABASE_SETUP.md](./SUPABASE_SETUP.md).
